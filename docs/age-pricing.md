# Возраст участников и индивидуальные билеты

Ветка `feature/age-aware-ticket-pricing` основана на незамерженной
`feature/meals-and-trip-budget` (`52afdf7`). Проверенный коммит реализации — `1c23fe6`.
Миграция `0012` добавляет необязательный возрастной профиль участника в PostgreSQL.

## Использование

В карточке участника можно указать целое число лет на начало поездки **или** дату
рождения. Неизвестный возраст допустим. Число лет неизменно на протяжении поездки;
по дате рождения возраст вычисляется отдельно на каждый день посещения.
Возраст из свободного текста пока не извлекается — его нужно проверить в форме.
Состав группы и возраст замораживаются при создании запроса: последующее изменение
профиля не переписывает сохранённые запросы, цены и маршруты.

У посещения показаны общая сумма, имена участников, возраст на дату посещения,
индивидуальная стоимость и основание тарифа. Смешанные тарифы складываются,
единой усреднённой цены «на человека» нет. Каталог до расчёта показывает обычный тариф.

## Проверенный справочник

Проверка 25 октября 2026, до 22 ноября 2026. Свежесть картографического источника
проверяется отдельно и этим этапом не продлевается. Суммы в EUR, границы включены.

| Место | Тарифы по возрасту | Источник |
| --- | --- | --- |
| Jardim Zoológico de Lisboa | 0–2: 0; 3–12: 19; 13–64: 31; 65+: 22 | [Оператор](https://www.zoo.pt/pt/visitar/precos/) |
| MAAT | 0–12: 0; 13+: 16, обычный тариф нерезидента | [Оператор](https://www.maat.pt/pt/planear-visita) |
| Пять станций Museu do Porto: Reservatório, Aurélia/Sofia, Romântico, Guerra Junqueiro, Douro/Vinho | 0–17: 0; 18–65: 4; 66+: 2. Бесплатное воскресенье имеет приоритет | [Музейная сеть](https://museudoporto.pt/info-util/) |
| Monserrate | 6–17: 10; 18–64: 12; 66+: 10 | [Оператор](https://www.parquesdesintra.pt/pt/planear-a-visita/horarios-e-precos/) |
| Capuchos | 6–17: 9; 18–64: 11; 66+: 9 | [Оператор](https://www.parquesdesintra.pt/pt/planear-a-visita/horarios-e-precos/) |

У двух объектов Синтры возраст 0–5 и ровно 65 лет оставлены непроверенными:
использованная страница неоднозначна. Применяется обычная цена с основанием
`regular_fallback_no_age_band`; бесплатный вход не предполагается. Это **9 мест**
с проверенными диапазонами, а не полный справочник льгот Португалии.

MAAT требует сопровождения детей взрослыми. Числовые пороги **до 18 лет / 18+**
для проверки — консервативное правило проекта, а не цитата возрастной границы
оператора. Несовершеннолетний без взрослого или неизвестный возраст кого-то в группе
исключают MAAT; если он обязателен, API просит уточнить состав. Родство и право
сопровождения не подтверждаются. Ограничения отдельных услуг, например канатной
дороги зоопарка, не переносятся на вход во весь зоопарк.

Без возраста, при истечении проверки льгот или отсутствии проверенного диапазона
применяется обычный тариф с объяснением. Просроченные условия допуска не игнорируются:
место исключается. Семейные пакеты, скидки резидентов/студентов, акции в день рождения
и онлайн не применяются автоматически. Документы для льготы проверяет оператор.

## Контракт и границы

`PUT /api/v1/groups/{group_id}/members/{user_id}/age-profile` принимает
`{"age_on_start":8}` или `{"birth_date":"2018-10-01"}`; пустой объект сбрасывает
возраст в «не указан». Допустимый возраст на даты поездки — 0–120 лет.

Правило `age-tariffs-v1` хранится с источником и сроками в версиях каталога PostgreSQL.
Перед оптимизацией `individual-age-pricing-v1` строит вектор цен участников для
каждого места и дня. Greedy, Beam, CP-SAT, оценка маршрута, бюджет и независимый
валидатор используют точную сумму этого вектора. Сохранённый `Visit` содержит
`group_cost` и `participant_prices`; `cost_per_person` равен null при разных тарифах.
Валидатор сверяет суммы с эталоном; старые результаты читаются с прежними ценами.
Возраст и персональные цены не попадают в публичный индекс Qdrant или ключи кэша
расстояний Redis. Политика объяснений — `grounded-explanation-v7-age-pricing`;
в LLM передаются вычисленные факты, без даты рождения.

Питание пока использует **одинаковый конкретный заказ для каждого, включая детей**.
Детские порции, тарифы перелётов, трансферов, кроватей и заселения не моделируются;
жильё и транспорт остаются пользовательскими оценками на группу. Возраст сам по себе
не меняет интересы или темп — это отдельные явные параметры.

## Проверка и запуск

603 backend-теста с PostgreSQL, Redis и Qdrant, 25 frontend-тестов, Ruff и сборка
прошли. Проверены границы возраста, день рождения внутри поездки, бесплатные даты,
сопровождение, просроченные правила, подмена сумм, бюджет и неизменность истории.
На живом API прошли 12 сценариев: три города × три алгоритма и ещё три двухдневных
расчёта с обедами, жильём, транспортом и резервом. Для семьи 30/35/8 зоопарк стоит
**31 + 31 + 19 = 81 EUR**, а не 93 EUR. [Результаты](age-pricing.json).
Каталоги опубликованы, публичные индексы проверены. Порты: интерфейс `3001`, API `8001`.
