# Стоимость каждого посещения

Ветка `feature/per-visit-prices` создана от `feature/comfortable-trip-pace`.
Карточки посещений в расписании показывают сумму на сохранённый состав группы
и цену на человека. Для одного участника показывается стоимость посещения,
для нулевой цены — «Бесплатно».

Новые ответы и сохранённые маршруты содержат `cost_per_person` и `group_cost`
в каждом элементе `result.visits` и `result.days[].visits`. Значения — целые
евроценты из тех же дневных входов планировщика, что определяют итоговую сумму.
Это стоимость билета либо конкретного заказа для гастрономической остановки.
Дополнительные услуги, питание вне учтённых заказов и транспорт не включаются.
Схема БД не меняется: поля добавлены в JSON результата, миграция не нужна.

Для старых результатов интерфейс использует `places_snapshot` соответствующего
дня, затем его сохранённые данные POI. Общий обзор другого дня или текущий каталог
не используется для восстановления цены многодневного маршрута.
Если цена не была сохранена, показывается «Стоимость посещения не сохранена».
Отсутствие данных не считается бесплатным входом. История в БД не переписывается.

Проверено совпадение цен посещений с суммами дней и всего периода, разные цены
по датам, состав группы, бесплатные посещения и чтение сохранённых результатов.
528 backend-тестов (включая PostgreSQL, Redis, Qdrant), 17 frontend-тестов и
production build прошли.
