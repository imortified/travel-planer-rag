# Три цветовые темы

Ветка `feature/warm-cool-dark-themes` основана на ещё не слитой
`feature/accounts-and-saved-travellers`. Main не менялся.

В правой части шапки доступны три двухцветных кружка с вертикальным разделением:

- Тёплая: исходная молочная палитра с терракотовым акцентом и зелёными деталями.
- Холодная: бело-голубые поверхности и синий акцент.
- Тёмная: графитово-синие поверхности, светлый текст и мягкий голубой акцент.

Переключатель работает на форме входа/регистрации и в планировщике. Выбранный
кружок отмечен обводкой; есть названия, подсказки и управление с клавиатуры.
Первое посещение открывает тёплую тему. Выбор сохраняется в браузере в
`localStorage["travel-theme"]`, сохраняется после выхода из аккаунта и
синхронизируется между открытыми вкладками. Смена системной темы не заменяет
явный выбор пользователя. Настройка относится к браузеру, не к серверному аккаунту.

Данные поездки, состав группы, введённая форма и выбранный маршрут не меняются
при переключении. Структура карточек, формы, сравнения и расписания сохранена;
новый элемент добавлен только в шапку. Исходные цвета тёплой темы вынесены в
переменные без замены значений. Размеры существующих блоков в globals.css не
переписывались. В узкой шапке переключатель и метка периода могут переноситься.

## Реализация

`frontend/app/themes.css` содержит палитры и оформление переключателя;
globals.css использует общие переменные для фона, текста, полей, статусов,
визовых блоков, бюджетов, отелей, перелётов и карты. `color-scheme` переключает
также нативные элементы формы. Успех/ошибка/визовые предупреждения сохраняют
свои различимые семантические цвета.

`frontend/lib/themes.ts` содержит допустимые ID и небольшой статический скрипт
восстановления выбора до первого отображения страницы. Скрипт в head меняет
только data-theme у html; React suppressHydrationWarning применяется к этому
элементу. На сервере всегда используется безопасная тёплая тема. Неизвестное
сохранённое значение возвращает тёплую; при запрете localStorage выбор работает
в текущей вкладке без исключений.

ThemeProvider и ThemeSwitcher находятся в
`frontend/app/components/theme-switcher.tsx`. React-контекст управляет выбранной
кнопкой; CSS применяет палитру ко всему документу. Выбор темы не вызывает API.

Карта обновляет фон и обводки через MutationObserver для data-theme, не пересоздавая
карту, маркеры и расчёт. Цвета дней остаются постоянными, чтобы не менять смысл
легенды при переключении. Панели управления, popup, стрелка popup и атрибуция
подстраиваются под палитру. Подложка OpenStreetMap по-прежнему включается явно;
изображения внешних тайлов не перекрашиваются.

## Проверки

- 35 frontend-тестов: существующие сценарии, допустимые темы, восстановление
  до первого отображения, повреждённое/недоступное хранилище. Для новых палитр
  контраст основного текста, подписей полей и кнопок не ниже 4,5:1.
- Production build с проверкой TypeScript пройден.
- Отдельно сопоставлены исходные CSS-объявления с новой тёплой палитрой после
  раскрытия переменных: прежние цвета и объявления сохранены.
- В браузере проверены все темы на форме входа, после входа, в сравнении маршрутов
  и на карте реального двухдневного тестового маршрута Lisbon. Тёмная тема
  восстановилась после reload. Переключение клавишей Enter сохранило введённый
  бюджет формы и уже открытый маршрут; другая открытая вкладка получила смену
  палитры автоматически. Ошибок hydration не обнаружено.
- Переключатель просмотрен на широком экране 1265 px и в узкой панели 477 px:
  кружки доступны, шапка и форма не перекрываются.

Скриншоты находятся локально в `.local/evaluations/theme-cool.png`,
`theme-dark.png`, `theme-dark-map.png`. Тестовые поездки принадлежат отдельному
синтетическому аккаунту; прежняя история пользователя не переносилась.
Backend, схема БД, зависимости и алгоритмы не менялись.

Проверки и запуск из frontend:

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run start -- --port 3001
```

В текущей рабочей копии готовая сборка запускается на прежнем порту 3001.
Чтобы получить обновлённый интерфейс в старой открытой вкладке, обновите страницу.
