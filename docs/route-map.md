# Карта маршрута и дневные сегменты

Этап `feature/route-map-acceptance` основан на `feature/cp-sat-experiments`.
Реализует FR-29 на уровне POI-to-POI из раздела 3.2 ТЗ.

## Поведение

- MapLibre GL JS 6.15.0 загружается только для результата с координатами, в клиентском
  компоненте. Worker включён в сборку Next/Turbopack, CDN для библиотеки не нужен.
- «Все дни» и отдельный день показывают только посещения выбранного варианта.
  Цвет обозначает день; метка `2·3` означает третье посещение второго дня.
- Кнопка места в списке и маркер открывают название и сохранённое время посещения.
  Кнопки доступны с клавиатуры, карта поддерживает стрелки и масштабирование.
- Координаты берутся из `result.days[].data_context`; при отсутствии дневного снимка —
  из `result.data_context`. История не запрашивает текущий каталог, OSM или OSRM.
  Координаты имеют порядок `[longitude, latitude]`, неполные и некорректные значения
  не попадают на карту. Географию для демо не придумываем.
- Каждый непустой день начинается в сохранённом `origin`, если он есть. Обратная дуга
  не добавляется. Пропуск координат разрывает линию: неизвестная точка не обходится
  новым прямым переходом между её соседями.
- Пунктир — порядок POI, **не дорожная геометрия**. OSRM сейчас сохраняет матрицу
  времени, а не маршрут по улицам. Карта не меняет стоимость, переезды, F и расписание.
- При переключении альтернативы сбрасываются выбранный день и место. Пустые дни
  остаются в переключателе. Без координат показывается список посещений.
- При недоступности WebGL/worker остаётся список; при ошибке подложки — сообщение
  и возможность выключить её. Отключённая подложка не мешает отображению сегментов.

## Подложка

По умолчанию сетевой подложки нет; пользователь включает OpenStreetMap кнопкой.
Стандартный URL — `https://tile.openstreetmap.org/{z}/{x}/{y}.png`, атрибуция видима
на карте. Используется обычный браузерный HTTP-кэш. Предзагрузки города, скачивания
для офлайн-использования и прокси тайлов нет. Доступность подложки не гарантирована.
Отключённая подложка не означает полноценный офлайн-режим приложения.

Настройка worker соответствует [инструкции MapLibre для Turbopack](https://maplibre.org/maplibre-gl-js/docs/#esm).
Параметры карты: [Map API](https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/).
Использование стандартной подложки: [политика OSMF](https://operations.osmfoundation.org/policies/tiles/).

## Проверка

Из `frontend`: `npm ci`, `npm test`, `npm run build`. Тесты запускаются встроенным
Node test runner с TypeScript stripping (проверено на Node 22.15.0); дополнительный
тестовый фреймворк не устанавливается. Восемь тестов проверяют порядок координат,
снимки дней, разрыв линии, фильтр, пустые дни, демо и альтернативы.

Приёмочные сценарии и фактический протокол: [acceptance.md](acceptance.md).
Миграции БД и новые серверные сервисы для карты не требуются.
